A program that writes one out-of-office auto-reply line, 140 characters or fewer, to `/output/entry.txt` — an entry for make.fun's "The Funniest Out-of-Office" bounty, $2 in USDC.

The line:

> I'm away. The last person who emailed me 'quick question' is still waiting — it's been 11 months.

The setup is a phrase every office worker recognises: the "quick question" email. The twist is what happened to the last person who sent one — they are still waiting, eleven months later — so the auto-reply quietly admits the inbox never answers at all.

## Run it

```sh
python3 main.py
```
